# 🌸 Аффирмации — Мобильное PWA Приложение (Node.js & JSX)

Красивое, медитативное мобильное PWA-приложение для ежедневных аффирмаций с гибкой настройкой **графика Push-уведомлений** для каждой отдельной фразы, генератором атмосферных звуков, озвучкой текста и дыхательными практиками.

---

## ✨ Ключевые возможности

1. 🎴 **Дзен-карточки (Aesthetic Cards & Gestures)**
   - Полноэкранный режим с поддержкой свайпов (влево/вправо) и тактильной отдачей (Haptics).
   - 8 авторских визуальных тем (Океан & Аврора, Золото & Изобилие, Нежная Роза, Изумруд, Лаванда, Космос и др.).
   - Выбор типографики (Serif, Sans, Рукописный шрифт).
   - Озвучивание аффирмации вслух приятным голосом (Web Speech API).
   - Синтез звука тибетской поющей чаши (432 Гц) и фоновый шум океана (Web Audio API).
   - Добавление в избранное с праздничной анимацией конфетти.
   - Поделиться фразой через системное меню шеринга (Web Share API) или скопировать в буфер.

2. ⏰ **Индивидуальный график Push-уведомлений для каждой аффирмации**
   - Возможность включать/выключать уведомления персонально для каждой фразы.
   - Выбор точного времени доставки (например: `08:00`, `13:00`, `21:30`) с быстрыми шаблонами (Утро, День, Вечер, Сон).
   - Выбор дней недели (Каждый день, Будни, Выходные, или произвольные дни).
   - Настройка вибрации и звукового сопровождения.
   - Кнопка **«Тестовый пуш»** для мгновенной проверки уведомления прямо на телефоне.
   - Серверный планировщик `node-cron` на Node.js, рассылающий Web Push даже при закрытом браузере.

3. 📚 **Библиотека и создание своих аффирмаций**
   - Удобный поиск и фильтрация по категориям (Спокойствие, Любовь к себе, Успех, Здоровье, Отношения, Мотивация).
   - Фильтры «Только избранные» и «С активным графиком».
   - Модальное окно создания и редактирования с предпросмотром в реальном времени и встроенной настройкой расписания.

4. 🧘 **Дыхательные практики и Медитация**
   - Практика «4-7-8 Релакс» для снятия тревожности и перед сном.
   - Практика «Квадрат 4-4-4-4» для концентрации.
   - Анимированный пульсирующий круг с отображением фокусирующей аффирмации на каждый цикл.

5. 📱 **Полноценный PWA (Progressive Web App)**
   - Поддержка офлайн-режима благодаря `Service Worker` и кэшированию.
   - Установка на экран смартфона (Android и iOS Home Screen).
   - Поддержка Web Push Notifications по стандарту W3C с использованием VAPID ключей.

## 🚀 Запуск проекта

### 1. Запуск в режиме разработки (Backend + Frontend)
```bash
npm run dev
```
- Сервер API и Web Push запустится на порту `3001`
- Клиент Vite запустится на порту `5173` с автоматическим проксированием API.

### 2. Запуск в режиме Production (единый сервер Node.js)
```bash
npm run build
npm start
```
Приложение откроется на `http://localhost:3001`.

## 📲 Как установить на смартфон и включить Push-уведомления

### 🍏 На iPhone / iPad (iOS 16.4+):
1. Откройте приложение в браузере **Safari**.
2. Нажмите кнопку **«Поделиться»** (иконка со стрелкой вверх) в нижней панели Safari.
3. Выберите пункт **«На экран "Домой"»** (Add to Home Screen).
4. Запустите приложение с иконки на рабочем столе.
5. Во вкладке **«График»** нажмите кнопку **«Включить пуш-уведомления»** и подтвердите запрос.

### 🤖 На Android:
1. Откройте приложение в браузере **Chrome** или **Яндекс.Браузер**.
2. Нажмите появившуюся кнопку **«Установить приложение»** или выберите «Добавить на главный экран» в меню браузера.
3. Разрешите уведомления при запросе.

## 🛠 Технологический стек
- **Frontend**: React 18, JSX, Tailwind CSS, Lucide Icons, Canvas Confetti, Web Audio API, Web Speech API, Service Worker API.
- **Backend**: Node.js, Express, `web-push` (W3C Web Push Protocol, VAPID), `node-cron` (фоновый планировщик).
